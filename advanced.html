Advanced: paying less, reusing more

Gas is the price of every line. These four contracts measure where it goes, including one popular trick that no longer helps.

  1. Custom errors are cheaper
  2. Pack your storage
  3. Inheritance and interfaces
  4. unchecked in loops

01 Custom errors are cheaper

A custom error (error NotOwner(address caller)) replaces a require string. The string has to be stored in the contract; the error is a 4-byte code plus arguments.

What it shows. Deploying the custom-error version cost 109,275 gas instead of 123,679 (12% less). At call time the difference is small: 21,283 against 21,344. And the error carries data: the revert told us exactly who was refused, NotOwner(Bob).

02 Pack your storage

Storage comes in 32-byte slots. Three uint256 fields take three slots; a uint64, a uint64 and a uint128 fit in one.

What it shows. Writing the same three numbers cost 88,096 gas in three slots and 44,174 in one: 50% less, because the expensive part is touching a slot, not the size of the number. Packing only pays when the fields are written together and the smaller types are big enough for your values.

03 Inheritance and interfaces

An interface lists functions without code; an abstract contract can hold shared code; a contract can inherit from both. Here Greeter gets onlyOwner from Owned.

What it shows. The modifier came from the parent contract and still did its job: Bob was refused with NotOwner(), an error declared in Owned, not in Greeter.

04 unchecked in loops

Since Solidity 0.8, arithmetic is checked: an overflow reverts. Wrapping a loop counter in unchecked { ++i; } used to save gas by skipping that check.

What it shows. Not any more. At 1,000 iterations the plain loop used 123,284 gas and the “optimised” one 123,306. That is 22 gas more for the manual version. Since 0.8.22 the compiler removes the overflow check from a simple for loop counter by itself, so writing it by hand only adds instructions. Measure before you optimise. (These are read-only calls, so the figures are execution gas, without the 21,000 base cost of a transaction.)

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
