Examples

Three complete contracts

The contracts from this site’s original repository, unchanged, each run through a short story. One of them has a bug that only shows when it runs.

  1. Voting systemThe owner creates proposals; each address votes once.8 transactions in the run, 3 reverted
  2. Pet adoptionThe owner lists pets with a fee; anyone can adopt one by paying it, and gets any overpayment back.5 transactions in the run, 2 reverted
  3. Payment for workThe employer deposits ether and credits workers; workers withdraw what they are owed. As written, it can promise more than it holds.7 transactions in the run, 1 reverted

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
