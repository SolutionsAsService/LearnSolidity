Run it

Run the contracts yourself

A fresh chain runs in this page: five accounts with 1,000 test ether each, and the contracts from this site, precompiled. Pick who you are and call any function. Nothing leaves your browser and the ether is not real. The EVM is a 882 KB download.

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
