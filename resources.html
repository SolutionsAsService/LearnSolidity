Resources

Where to go next

A short list, chosen for learners. These are other people’s sites; this site has no connection to them.

Reference

  • Solidity documentationThe language reference, by the Solidity team. The source of truth for every rule on this site.
  • Mastering EthereumAntonopoulos and Wood’s book, free on GitHub.
  • Solidity by ExampleShort, runnable contracts for one idea each.

Practice

  • CryptoZombiesAn interactive course that builds a game step by step.
  • Speedrun EthereumBuild-and-ship challenges.
  • EthernautSecurity puzzles: break a contract to pass each level.

Tools

  • RemixWrite, compile and deploy in the browser.
  • FoundryTests written in Solidity, a fast local chain, gas reports.
  • HardhatA JavaScript development environment.
  • OpenZeppelin ContractsAudited building blocks: tokens, access control, reentrancy guards.

Security

  • Smart Contract Best PracticesKnown attacks and how to avoid them.
  • Not So Smart ContractsReal vulnerable contracts, with the fix.
  • SWC RegistryA numbered catalogue of weakness types. Older, but the categories still hold.

Ask

  • Ethereum Stack ExchangeQuestions and answers.
  • r/ethdevA developer forum.

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
