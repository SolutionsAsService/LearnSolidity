Basics: state, calls and saying no

Four small contracts. Each one was compiled and run; the table under it is what happened.

01 A number that lives on chain

A contract is code plus storage. count is a state variable: it lives in storage and keeps its value between transactions. Reading it is free; changing it costs gas.

Terms

smart contract
A program stored on a blockchain. Anyone can call its functions; nobody can quietly change its code.
storage
The data a contract keeps between transactions. It is written to every node, which is why writing it costs the most gas.
gas
The unit of work the network charges for. Every operation has a fixed gas cost; storing data is the expensive part.
transaction
A signed message that changes the chain: deploys a contract, calls a function or sends ether. It costs gas.

What it shows. The same function cost 43,405 gas the first time and 26,305 the second. Turning a zero into a non-zero value is the most expensive write there is; changing an existing value is cheaper. Setting it back to zero earns a refund, so reset() cost only 21,422. Notice that Bob, not the deployer, could reset it: nothing here checks who is calling. What does gas cost in money? You pay gas × gas price. At a gas price of 20 gwei (0.00000002 ETH), the first increment() would cost 43,405 × 20 gwei = 0.000868 ETH; gas prices change from block to block, so check the current one before you deploy.

02 Mappings, structs and events

A mapping is a lookup table from keys to values; a struct groups fields. record() writes both and emits an event.

Terms

event
A log line a contract emits. Apps listen for events; contracts cannot read them.

What it shows. Every key of a mapping already exists and reads as zero: Carol never wrote, and amountOf(Carol) returned 0, not an error. Each record() left a Recorded event in the transaction log, which is how a website would learn about it.

03 require: saying no

require(condition, "message") stops a transaction when the condition is false and undoes it. msg.sender is whoever called.

Terms

msg.sender
The address that called this function directly: a person’s account or another contract.
revert
A transaction that stops and undoes everything it did. The sender still pays for the gas used up to that point.

What it shows. Bob’s call reverted with the contract’s own words, “Only the owner can set the limit”, and still cost him 21,552 gas: a refused transaction is not free. The owner’s valid call went through for 26,477.

04 Receiving and sending ether

A contract can hold ether. receive() runs when someone sends ether with no function call; payable marks addresses and functions that may receive it.

Terms

ether (ETH)
The currency of Ethereum. 1 ETH = 10¹⁸ wei, the smallest unit.

What it shows. Two plain transfers left the contract holding 1.5 ETH. Bob could not smash it; the owner could, and the balance went to 0 ETH. The transfer uses call and checks its result: a failed send that nobody checks is a classic bug.

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
