Pet adoption

The owner lists pets with a fee; anyone can adopt one by paying it, and gets any overpayment back.

Run it yourself (a 882 KB download)

What happened when it ran

What it shows. Paying 0.05 ETH for a 0.1 ETH pet reverted (“Insufficient funds to adopt pet”). Bob then sent 0.25 ETH and the contract refunded the 0.15 ETH difference before paying the owner. Carol was too late (“Pet already adopted”). It uses transfer, which forwards only 2,300 gas: if the owner were a contract with a busy receive(), every adoption would fail.

Terms

transaction
A signed message that changes the chain: deploys a contract, calls a function or sends ether. It costs gas.
revert
A transaction that stops and undoes everything it did. The sender still pays for the gas used up to that point.
event
A log line a contract emits. Apps listen for events; contracts cannot read them.

The contract

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 494 transactions (96 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
