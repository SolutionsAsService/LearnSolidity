About

How this site is made

A free, open-source way to learn Solidity by watching contracts run. No accounts, no tracking, no course to buy.

Every number is a measurement

  1. The 16 Solidity files in contracts/ are compiled with solc 0.8.28 (optimizer on, 200 runs, Cancun EVM).
  2. Each lesson has a script in tools/scenarios.mjs: who deploys, who calls what, with how much ether.
  3. The scripts run in EthereumJS, a JavaScript implementation of the Ethereum Virtual Machine, on a fresh chain with five accounts (Alice, Bob, Carol, Dave and Mallory). Every transaction's gas, return value, events and revert reason is recorded in data/runs.json.
  4. The pages are written from that file. The text quotes it rather than retyping it.

Gas figures are for the whole transaction, including the 21,000 base cost every transaction pays; read-only calls show execution gas only and are marked with an asterisk. On a public network your numbers will match only for the same compiler, settings and EVM version.

What this site is not

It is not an audit and not financial advice. The contracts are teaching code: small, readable, deliberately incomplete. Before you deploy anything that holds real money, have it tested and reviewed.

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
