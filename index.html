Solidity you can watch run.

23 small contracts, compiled and run on a real Ethereum Virtual Machine: every transaction’s cost in gas, and every one that was refused and undone. The red one is a bug from this site’s own examples.

Three levels, then three complete contracts

  1. BasicsState, calls, require, ether. 4 contracts.
  2. AdvancedWhere gas goes: errors, packing, inheritance, loops. 4 contracts.
  3. SecurityReentrancy, overflow, tx.origin, unbounded loops: each run, then run again against the fix.
  4. ExamplesThree complete contracts, one with a money bug.

Things the runs taught us

  • Refusing costs gas. A reverted call still charged its sender 21,552 gas. See it
  • A popular trick stopped working. unchecked { ++i; } in a loop now costs 22 gas more over 1,000 iterations, not less. See it
  • The textbook reentrancy example no longer drains under 0.8. It reverts on underflow, which hides the bug. See one that does

Every contract on this site was compiled with solc 0.8.28 and run in an in-memory EVM (EthereumJS, Cancun rules) when the site was built: 16 source files, 23 contracts, 491 transactions (93 listed on these pages; the rest are setup calls such as members joining, counted where they happen), 17 reverted on purpose. Run cd tools && npm ci && npm run build to reproduce every number. Nothing here is financial or security-audit advice.
